# AI 鉴图评分（astrbot_plugin_image_judge）

让机器人对群友发的图片**打分 + 锐评吐槽**的娱乐插件。群友发图，机器人调用你
AstrBot 里**已经配置好的多模态模型**，给出 0-100 评分、一句话理由和一段吐槽。

> ⚠️ **纯娱乐插件**：评分和吐槽都是 AI 生成的，仅供参考，开心就好。

## 功能特性

- **两种触发方式**
  - 关键词触发（默认）：回复图片（或直接发图），再发送“打分 / 鉴图 / 点评 / 评价 / 锐评”即可触发；无图片上下文时，只有消息基本就是一条鉴图指令才响应，普通聊天里出现“评价 / 点评”等词不会误触发
  - 自动触发（可选）：开启后群内图片按概率自动被点评，带群白名单、冷却、每小时上限和免打扰时段，可按群用管理指令调整
- **头像鉴图**：发送“锐评 @某人”，自动抓对方 QQ 头像来打分吐槽（主要支持 QQ 平台）
- **鉴图排行榜**：`鉴图榜` 查看本群今日高分榜与“最惨”记录，`鉴图榜 本周` / `鉴图榜 总` 切换时间范围，所有人可查
- **个人战绩**：`鉴图榜 @某人` 或 `我的鉴图` 查看被评次数、平均分、最高/最低分
- **群管理指令**：`鉴图开启` / `鉴图关闭` / `鉴图概率 0-100` / `鉴图状态`，群主、群管理员或 Bot 管理员可按群调整自动鉴图
- **回复图片触发**：回复一条图片消息并附关键词即可打分（自动从被回复消息取图，适配 OneBot/QQ）
- **三种吐槽风格**：毒舌 / 客观 / 彩虹屁，命令里可直接指定（如 `打分 毒舌`）
- **五种卡片主题**：霓虹 / 极简 / 复古 / 赛博朋克 / 马卡龙，命令里可临时指定（如 `打分 复古`）
- **两种输出形式**：默认纯文本；可切换渲染成评分卡片图（大字分数 + 星级 + 吐槽）
- **防刷机制**：按用户冷却 + 每日次数上限 + 每群每小时上限 + 免打扰时段；忽略表情包 / GIF（可配置）
- **重复图缓存**：同一张图在有效期内重复鉴图直接复用上次结果，不再调模型，省额度
- **无需额外 API Key**：复用 AstrBot 已配置的模型商

## 安装

1. 将 `dist/astrbot_plugin_image_judge-v0.5.0.zip` 在 AstrBot WebUI 的
   “插件管理”中上传安装（或在 `AstrBot/data/plugins/` 下解压）；
2. 安装依赖：`pip install -r requirements.txt`（aiohttp、Pillow）；
3. 在插件配置中确认“鉴图专用模型”为空（自动用当前会话模型），
   或指定一个**支持图片输入**的模型；
4. 重载插件。

## 使用

```
# 回复一张图片 + 关键词
（回复图片）打分

# 指定风格
（回复图片）打分 彩虹屁

# 指定卡片主题（仅在 render_mode=card 时生效）
（回复图片）打分 复古

# 当前消息直接带图 + 关键词
[图片] 鉴图

# 头像鉴图（无图片时 @ 某人）
锐评 @张三

# 群管理指令（鉴图榜、个人战绩、鉴图状态所有人可查，其余需群主/群管理员/Bot 管理员）
鉴图榜            # 本群今日高分榜（附“最惨”记录）
鉴图榜 本周       # 近 7 天榜单；鉴图榜 总 = 历史总榜
鉴图榜 @张三      # 查张三的个人战绩（同样支持 本周 / 总）
我的鉴图          # 查自己的个人战绩（等价于 鉴图榜 @自己）
鉴图开启          # 本群开启自动鉴图（跟随全局总闸）
鉴图关闭          # 本群关闭自动鉴图
鉴图概率 50       # 本群自动鉴图概率设为 50%
鉴图状态          # 查看本群当前设置（所有人可用）
```

- 指令词之间可以带空格（`鉴图 开启`、`鉴图 概率 50` 都能识别），中文输入法
  自动加空格不影响使用
- 关键词可用 `|` 分隔多个，默认：`打分|鉴图|点评|评价|锐评`
- 关键词是子串匹配，为避免“帮我评价一下这个方案”这类普通聊天被误触发：
  消息带图 / 回复 / @目标时照常触发；否则只有消息基本就是一条指令
  （去掉触发词、风格词、主题词后剩余内容很短，如“打分”“锐评吧”）才响应
- 自动触发只在“可能带图”的消息上掷概率，取到图才计入群冷却与每小时配额，
  纯文本不浪费机会；自动触发失败保持静默，也不消耗发图者的个人冷却与每日额度
- 群管理指令按群持久化保存在 AstrBot 插件数据目录，重启不丢失；
  全局 `enable_auto_trigger` 仍是总闸（关闭即全停）
- 输出文本示例：

```
鉴图结果（毒舌）：72/100 分 ★★★★☆
理由：构图不错，但饱和度有点高。
吐槽：像是调色师喝了三杯浓缩咖啡后的作品。

鉴图榜（今日）
1. 95 分 — 10001：构图、光影、情绪全都在线。
2. 88 分 — 10002：色彩大胆，但主体略糊。
3. 41 分 — 10003：像素风格，主打复古。
最惨：10003 41 分

10001 的鉴图战绩（今日）
被评 3 次 · 平均 71.3 分
最高 95 分 · 最低 41 分
```

## 配置说明

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `trigger_keywords` | `打分\|鉴图\|点评\|评价\|锐评` | 触发关键词，`\|` 分隔 |
| `enable_auto_trigger` | `false` | 是否对群内所有图片自动鉴图（费额度，建议配合白名单） |
| `auto_trigger_probability` | `20` | 自动触发概率（%） |
| `auto_trigger_cooldown_seconds` | `300` | 同群自动触发冷却（秒） |
| `group_allowlist` | 空 | 自动触发群白名单，逗号分隔；留空=所有群 |
| `quiet_hours` | 空 | 自动触发免打扰时段，如 `23:00-08:00`；留空=不启用 |
| `group_hourly_limit` | `0` | 每群每小时自动触发上限，`0`=不限 |
| `private_enable` | `true` | 允许私聊使用 |
| `enable_avatar_judge` | `true` | 头像鉴图（“锐评 @某人”），主要支持 QQ 平台 |
| `ignore_sticker` | `true` | 忽略表情包/贴图 |
| `ignore_gif` | `true` | 忽略 GIF 动图（关闭时自动取第一帧） |
| `max_images_per_message` | `1` | 单条消息最多鉴图张数 |
| `max_image_mb` | `8` | 单张图片大小上限（MB） |
| `vision_provider_id` | 空 | 鉴图专用模型；空=当前会话模型 |
| `style` | `毒舌` | 默认吐槽风格（毒舌/客观/彩虹屁） |
| `custom_prompt` | 空 | 自定义系统提示词（覆盖人设，仍要求三行格式输出） |
| `temperature` | `0.9` | 生成温度 |
| `timeout_seconds` | `60` | 模型请求超时 |
| `render_mode` | `text` | `text` 纯文本 / `card` 评分卡片图（需 AstrBot 配置 HTML 渲染） |
| `card_theme` | `霓虹` | 评分卡片主题（霓虹/极简/复古/赛博朋克/马卡龙），仅 `render_mode=card` 时生效 |
| `show_error_message` | `true` | 失败时是否提示 |
| `user_cooldown_seconds` | `60` | 同一用户冷却（秒） |
| `daily_limit` | `20` | 每用户每日上限 |
| `result_cache_seconds` | `600` | 相同图片结果缓存秒数，命中则不再调模型；`0`=关闭 |

## 注意事项

- **模型必须支持图片输入**（多模态）。如果你的默认模型不支持看图，
  请在“鉴图专用模型”中指定一个支持图片的模型；
- 每次鉴图都会消耗一次模型额度，`enable_auto_trigger` 请谨慎开启；
- QQ 图片存在防盗链，插件会先下载图片再发送给模型，图片下载失败时会自动跳过；
  下载带体积上限并在读取过程中限流，超大响应不会被整体读进内存；
- `result_cache_seconds` 命中缓存时不会调用模型，因此同一张图重复鉴图会得到
  完全相同的文案（这是省额度的预期行为，设 0 可关闭）；
- 本插件不记录、不上传任何图片到第三方服务，所有图片仅在你的 AstrBot
  与已配置的模型商之间传输。
