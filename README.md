# AI 鉴图评分（astrbot_plugin_image_judge）

让机器人对群友发的图片**打分 + 锐评吐槽**的娱乐插件。群友发图，机器人调用你
AstrBot 里**已经配置好的多模态模型**，给出 0-100 评分、一句话理由和一段吐槽。

> ⚠️ **纯娱乐插件**：评分和吐槽都是 AI 生成的，仅供参考，开心就好。

## 功能特性

- **两种触发方式**
  - 关键词触发（默认）：回复图片（或直接发图），再发送“打分 / 鉴图 / 点评 / 评价 / 锐评”即可触发
  - 自动触发（可选）：开启后群内图片按概率自动被点评，带群白名单和冷却控制
- **回复图片触发**：回复一条图片消息并附关键词即可打分（自动从被回复消息取图，适配 OneBot/QQ）
- **三种吐槽风格**：毒舌 / 客观 / 彩虹屁，命令里可直接指定（如 `打分 毒舌`）
- **五种卡片主题**：霓虹 / 极简 / 复古 / 赛博朋克 / 马卡龙，命令里可临时指定（如 `打分 复古`）
- **两种输出形式**：默认纯文本；可切换渲染成评分卡片图（大字分数 + 星级 + 吐槽）
- **防刷机制**：按用户冷却 + 每日次数上限；忽略表情包 / GIF（可配置）
- **无需额外 API Key**：复用 AstrBot 已配置的模型商

## 安装

1. 将 `dist/astrbot_plugin_image_judge-v0.1.0.zip` 在 AstrBot WebUI 的
   “插件管理”中上传安装（或在 `AstrBot/data/plugins/` 下解压）；
2. 安装依赖：`pip install -r requirements.txt`（aiohttp、Pillow）；
3. 在插件配置中确认“鉴图专用模型”为空（自动用当前会话模型），
   或指定一个**支持图片输入**的模型；
4. 重载插件。

## 使用

```
# 回复一张图片 + 关键词
（回复图片）打分

# 指定风格
（回复图片）打分 彩虹屁

# 指定卡片主题（仅在 render_mode=card 时生效）
（回复图片）打分 复古

# 当前消息直接带图 + 关键词
[图片] 鉴图
```

- 关键词可用 `|` 分隔多个，默认：`打分|鉴图|点评|评价|锐评`
- 输出文本示例：

```
鉴图结果（毒舌）：72/100 分 ★★★★☆
理由：构图不错，但饱和度有点高。
吐槽：像是调色师喝了三杯浓缩咖啡后的作品。
```

## 配置说明

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `trigger_keywords` | `打分\|鉴图\|点评\|评价\|锐评` | 触发关键词，`\|` 分隔 |
| `enable_auto_trigger` | `false` | 是否对群内所有图片自动鉴图（费额度，建议配合白名单） |
| `auto_trigger_probability` | `20` | 自动触发概率（%） |
| `auto_trigger_cooldown_seconds` | `300` | 同群自动触发冷却（秒） |
| `group_allowlist` | 空 | 自动触发群白名单，逗号分隔；留空=所有群 |
| `private_enable` | `true` | 允许私聊使用 |
| `ignore_sticker` | `true` | 忽略表情包/贴图 |
| `ignore_gif` | `true` | 忽略 GIF 动图（关闭时自动取第一帧） |
| `max_images_per_message` | `1` | 单条消息最多鉴图张数 |
| `max_image_mb` | `8` | 单张图片大小上限（MB） |
| `vision_provider_id` | 空 | 鉴图专用模型；空=当前会话模型 |
| `style` | `毒舌` | 默认吐槽风格（毒舌/客观/彩虹屁） |
| `custom_prompt` | 空 | 自定义系统提示词（覆盖人设，仍要求三行格式输出） |
| `temperature` | `0.9` | 生成温度 |
| `timeout_seconds` | `60` | 模型请求超时 |
| `render_mode` | `text` | `text` 纯文本 / `card` 评分卡片图（需 AstrBot 配置 HTML 渲染） |
| `card_theme` | `霓虹` | 评分卡片主题（霓虹/极简/复古/赛博朋克/马卡龙），仅 `render_mode=card` 时生效 |
| `show_error_message` | `true` | 失败时是否提示 |
| `user_cooldown_seconds` | `60` | 同一用户冷却（秒） |
| `daily_limit` | `20` | 每用户每日上限 |

## 注意事项

- **模型必须支持图片输入**（多模态）。如果你的默认模型不支持看图，
  请在“鉴图专用模型”中指定一个支持图片的模型；
- 每次鉴图都会消耗一次模型额度，`enable_auto_trigger` 请谨慎开启；
- QQ 图片存在防盗链，插件会先下载图片再发送给模型，图片下载失败时会自动跳过；
- 本插件不记录、不上传任何图片到第三方服务，所有图片仅在你的 AstrBot
  与已配置的模型商之间传输。
